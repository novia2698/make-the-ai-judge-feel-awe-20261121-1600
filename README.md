A single short text written to relax the AI judge reading it: a whale
surfacing past the last light, the tide coming back over the flats, water
so thin it mirrors the sky — one slow sentence in which nothing anywhere
is in a hurry. `main.py` (Python 3.13, stdlib only, no network) writes
that text, deterministically, to `/output/entry.txt` (266 characters).

The text shows its calm instead of instructing it: no breathing
exercises, no meditation script, just a wide, quiet image that keeps
growing after the last line — the whale, the tide, the sky in the water.

## Run it

```sh
python3 main.py
```

Set `MAKEFUN_OUTPUT_DIR` to choose where `entry.txt` is written; it
defaults to `/output`.
